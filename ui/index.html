Local-first. This page makes no network request except to a daemon you connect it to on 127.0.0.1. No fonts, scripts, or data are fetched from anywhere else.

Connect to a running daemon

Start it with agentrelay serve. It writes the address and a bearer token to .agentrelay/ipc.json. Copy both here — the token stays in this page's memory only, and is never stored or shown again.
