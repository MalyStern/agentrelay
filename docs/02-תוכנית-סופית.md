## א. מה השתנה אחרי ההפרכה — 12 התיקונים

זה הלב של הסבב הזה. כל שורה = טענה מקורית שלי → מה היריב הוכיח → התיקון שנכנס למסמך.

| **5** 🟠 | first-turn-אחרי-resume = בדיקת-מצב-בלבד (בקשה בפרומפט) | **פרומפט לא-אכיף — המודל יכול להתעלם ולערוך** | first-turn read-only נאכף ב-**PreToolUse guard שחוסם כל Write/Edit** עד שה-daemon מרים דגל אחרי אישור-checkpoint |
| **6** 🟠 | `git_head==checkpoint`, אחרת "שינוי חיצוני → עצור" | **פעילות-המערכת-עצמה (validator commit, merge-queue, auto-format) מזיזה HEAD** → מעיר בכל פעם | ה-daemon **חותם/מתייג את ה-commits שלו**; מבחין "שלנו" מ"זר". רק HEAD-זר מפיל ל-waiting_input |
| **7** 🟠 | resume אותו-session (בידול מ"restart נאיבי") | **קבצי-session של Claude ניתנים-לגיזום;** `--resume` נכשל שעות-אחרי, בדיוק בחלון-האיפוס | אימות-קיום-session **לפני** חלון-האיפוס, לא אחריו. גיבוי checkpoint→session-נקי מוזרק כשהמקורי אבד |
| **8** 🟠 | Stop-hook `block` כופה המשך "עד שהבדיקות עוברות" | **Claude משחרר אחרי 8 בלוקים-רצופים ללא-התקדמות** | completion-gating = ולידטורים (שכבה-2), לא הסתמכות על Stop-hook אינסופי |
| **9** 🟠 | kill-tree "הורג את **כל** העץ" | **Docker/WSL/SSE-MCP/דמונים-מנותקים בורחים מ-pgid/Job.** ב-Windows race אם לא CREATE_SUSPENDED | Windows: **CREATE_SUSPENDED→assign→resume**. מעקב-משאבים מעבר-לעץ: `docker events`, מצב-WSL, רישום-MCP; **reconciliation לפני שמסמנים "עצור"** |
| **10** 🟠 | allowed_paths ברמת-glob = אכיפה-דטרמיניסטית (גם ל-Codex) | **sandbox של Codex גס: אוכף גבול-workspace+רשת, לא `**/*.css` בתוך-workspace.** אכיפת-glob דורשת approval-per-patch (הורג throughput) | **טבלת-אכיפה מפורשת** (§ז.4): מה OS-sandbox-אכיף, מה דורש approval-intercept, מה advisory+drift. פער-Windows מתועד |
| **11** 🟡 | prompt-caching + deferred-tools = יכולת של AgentRelay | **תחת מנוי+CLI ה-AgentRelay לא בונה את בקשת-ה-API → אין שליטה ב-cache/הזמנת-prefix.** ואין חיוב-per-token → cache = latency/quota-warmth, לא כסף | מסומן "**via-API-mode בלבד**". מסירים כל רמיזת-חיסכון-כספי תחת מנוי. worktrees נפרדים = cache נפרד; subagents תמיד-קרים |
| **12** 🟡 | Event-Sourcing כליבה + hash-chain audit | **משלמים על ES *וגם* על טבלאות-מצב; projections לא-מוגדרות; דלתות-טקסט מפוצצות טבלה; hash-chain=תיאטרון לכלי-מקומי** | **היברידי:** append-only log להיסטוריה-אמיתית (checkpoints/quota/מעברי-מצב/validations/timeline-קליל) + טבלאות-מצב-משתנות כמקור-אמת-לנוכחי. `payload_ver`. **hash-chain יורד מ-v1.** דלתות-טקסט לא-נשמרות כאירועים |

**ומה שהיריב תקף אבל צדקתי:** מטריצת-היכולות (§2) — שמות-מתודות-App-Server, מנגנון-ה-hooks, מודל-ה-rate-limit, reset-banking, Tauri-kill-tree — **כולם אומתו מול מקורות-2026 ועמדו.** היריב-העובדתי כתב במפורש: *"לא הצלחתי להרוס את המטריצה."* וגם: `completion=validators=ראיות` (§7 שכבה-2) עומד — שם באמת אין הסתמכות-על-מודל.

"עצור" לא מוצג עד אימות-משאבים-חיצוני. זו הרחבת הכלל שהיריב דרש בצדק על **כל** ה-UI, לא רק ה-Savings-Dashboard.

<a name="matrix"></a>
## ג. מטריצת-יכולות מתוקנת (רק התיקונים; המלאה ב-[`00 §2`](00-מסמך-אב-תוכנית-בנייה.md))

**Claude Code:**
- ✅ Hooks: PreToolUse `exit 2` חוסם **לפני** בדיקת-הרשאות (גם תחת bypass) — **מאומת, עוגן-האכיפה.**
- ✅ PostToolUse `updatedToolOutput` **מחליף** את הפלט-שהמודל-רואה — **זה** הכלי ל-Output-Compressor (לא PreToolUse).
- ⚠️ `--input-format stream-json` — NDJSON פנימה, אבל **בין-turns, לא הזרקה-חיה-באמצע-turn.** steer רק בין-turns.
- ⚠️ Stop-`block` — כופה המשך, **תקרה 8 בלוקים-ללא-התקדמות.**
- ✅ 31 אירועי-hook. ✅ Agent-SDK session ל-JSONL ב-`~/.claude/projects/`, `session_id` ב-init.
- ⚠️ prompt-caching/deferred-tools — **API-mode בלבד**; תחת מנוי אין שליטה ואין חיסכון-כספי.

**Codex:**
- ✅ App-Server: `thread/{start,resume,fork,read,list}` · `turn/{start,steer,interrupt}` · `item/agentMessage/delta` · `turn/completed`. stdio/socket. (`newConversation`/`sendUserTurn` = legacy.)
- ⚠️ token-usage = notification נפרד **`thread/tokenUsage/updated`**, לא ב-turn/completed.
- ⚠️ שגיאת-מכסה באפ-סרבר = `UsageLimitExceeded` (עם `resets_at`/`resets_in_seconds`/`plan_type`).
- ✅ אין auto-resume (FR #21073 פתוח). ✅ token-based, 5ש+שבועי, בריכה-משותפת. ✅ reset-banking (רשמי; banked פג-30יום, restored פג-7יום).
- ⚠️ sandbox = גבול-workspace+רשת (OS-level), **לא glob-דק.** חלש ב-Windows.

**תשתית:**
- ✅ kill-tree דורש pgid(Unix)/Job-Object(Win). Windows: **CREATE_SUSPENDED→assign→resume** (אחרת race).
- ⚠️ keep-awake Win = **`ES_CONTINUOUS|ES_SYSTEM_REQUIRED`**; mac `caffeinate -s` (AC) / `-i`; Linux `systemd-inhibit` (דורש logind).

<a name="providers"></a>
## ו. אסטרטגיית-ספקים

ארבע קטגוריות, בסדר-עדיפות-מימוש:

### 1. Claude Code — **Agent SDK + Hooks** (Phase-1)
מנוע = subprocess שמריץ את ה-SDK (לא CLI-headless בלבד — כי רק SDK מאפשר `canUseTool`/transform שה-Context-Optimizer צריך, תיקון #1). Hooks לאכיפה: `PreToolUse` (block), `PostToolUse.updatedToolOutput` (compress/receipt), `Stop` (gate — עם מודעות ל-8-block-cap). resume דרך `session_id`.

### 2. Codex — **App-Server JSON-RPC** (Phase-3)
stdio/socket. usage מ-`thread/tokenUsage/updated`. אכיפה: OS-sandbox (גס) + approval-intercept (דק, בעלות-throughput). `codex exec --json` לצינון-קצר.

### 3. **ACP generic adapter** (Phase-3) — התובנה הגדולה של היריב-3
**ACP (Agent Client Protocol, Zed 2025)** = JSON-RPC 2.0 על stdio, "LSP לסוכני-קוד": session, filesystem, terminal, permissions, streaming. **~25 סוכנים כבר מדברים אותו:** Gemini CLI (`--acp`), Claude Code, Codex, OpenCode, Copilot CLI (preview), Junie (`--acp`), Cline, Devin (`devin acp`), Goose, OpenHands. **ה-Codex-adapter שלנו כבר מדבר JSON-RPC/stdio — האדריכלות מוכנה.** adapter-אחד = ~10 סוכנים. **מחליף את "future: Gemini/Cursor adapter" בפרוטוקול-אחד.**

### 4. **Cloud-delegated** (Phase-4) — קטגוריה שהטיוטה לא דמיינה
לא subprocess-מקומי-turn-אחר-turn, אלא **שיגור-משימה-לסוכן-מתארח וקבלת-PR:** Devin REST (`api.devin.ai/v3/sessions`) · GitHub Copilot **Agent-Tasks API** (assign `copilot-swe-agent[bot]`, prompt→PR). מתאים ל-units-ארוכים שלא-צריך-מכונה-מקומית-ערה.

**לא-לבנות-עליהם (dead-ends 2026):** Continue (נרכש/הוקפא), Roo Code (ארכיון), Amazon Q (עבר ל-Kiro closed), Windsurf (רובנד ל-Devin).

<a name="mechanisms"></a>
## ז. המנגנונים הקריטיים — מתוקנים

### ז.1 Context Optimizer — הגדרה-מחדש (תיקון #1, הכי-חשוב)
**האמת שהיריב אילץ:** דרך CLI+hooks אפשר **לחסום ולייעץ, לא להחליף**, ולא למנוע נתיב-קריאה-לא-מיורט (הסוכן יכול `cat` ב-Bash). לכן:
- **מנוע = Agent SDK מ-Phase-1** (`canUseTool` + transform-result), או **כלי-MCP-בבעלות-AgentRelay** (`ar_read`/`ar_test` שהסוכן חייב לקרוא במקום Read/Bash) — אז אנחנו בעלי-הבית על ה-I/O.
- **Output-Compressor** נאכף דרך **`PostToolUse.updatedToolOutput`** (מחליף באמת), לא PreToolUse.
- **File-Receipts:** ה-`hash` = מצב-אמת (הקובץ לא-השתנה). אבל ה-`summary` = **פלט-מודל** → מסומן **Estimated**, ולעולם-לא-מוצג-כ"הקובץ". קריאה-מלאה תמיד-זמינה.
- **Phase-0 spike חובה:** "האם המנוע-שנבחר מסוגל בכלל להחליף תוצאת-כלי?" — kill-test לפני-בנייה.

### ז.2 Resume — ריאקטיבי, מבחין-commits, אכיף (תיקונים #3,#5,#6,#7)
- **זיהוי:** ריאקטיבי מהשגיאה (אין מונה-חי ב-Claude-headless). לכן **units קטנים** = הפסקה-באמצע תמיד-בטוחה. חיזוי = Estimated-בלבד, לא מניע-checkpoint-קשיח לבד.
- **HEAD:** ה-daemon חותם commits (trailer/tag). רק HEAD-**זר** → waiting_input.
- **session:** אימות-קיום **לפני** חלון-האיפוס. אבד → checkpoint→session-נקי.
- **first-turn read-only נאכף בקוד:** PreToolUse guard חוסם כל Write/Edit עד דגל-daemon אחרי אישור-checkpoint. **לא פרומפט.**

### ז.3 Stop שבאמת עוצר (תיקון #9)
- Windows: CREATE_SUSPENDED→AssignProcessToJobObject→ResumeThread (Job עם KILL_ON_JOB_CLOSE).
- מעבר-לעץ: `docker events`→container-IDs · מצב-WSL-distro · רישום-SSE-MCP · דמונים-מנותקים. `external_resources` מנוטרת.
- **"עצור" לא מוצג עד reconciliation** שכל המשאבים-החיצוניים מתים. אחרת = שליטה-מזויפת (8.14).

### ז.4 טבלת-אכיפת-Guards (תיקון #10) — מפורשת פר-מנגנון
| Guard | Claude (Hooks) | Codex (sandbox/approval) | הערה |
|-------|----------------|--------------------------|------|
| no-push / no-deploy | PreToolUse block | OS-sandbox (רשת חסומה) | **דטרמיניסטי בשניהם** |
| no-network | PreToolUse block | OS-sandbox no-net | דטרמיניסטי |
| workspace-boundary | PreToolUse block | OS-sandbox workspace-write | דטרמיניסטי |
| allowed_paths **glob** (`**/*.css`) | PreToolUse block (מדויק) | **approval-intercept per-patch** (עלות-throughput) או advisory+drift | ⚠️ ב-Codex לא-חינם |
| no-dependency | PreToolUse block | approval-intercept | |
| Windows | מלא | **חלש** (אין Landlock/Seatbelt) → approval-בלבד | ⚠️ פער מתועד |

### ז.5 Keep-awake (תיקון #2)
Win `ES_CONTINUOUS|ES_SYSTEM_REQUIRED` (+display לפי-צורך) · mac `caffeinate` · Linux `systemd-inhibit`. + בדיקת-סוללה/חשמל + recovery-אחרי-restart.

<a name="security"></a>
## ח. אבטחה: סודות ובידוד — **הדבר #1 שחסר** (היריב-3)

*"התוכנית כולה על 'משימת-לילה בלי אדם', אבל לא הגדירה איך הסוכן מקבל secrets ואיך תוחם ה-blast-radius לפני-הריצה. deny-all ו-kill-tree מטפלים ב-אחרי; לא מונעים דליפה כשאין-יד-על-ההגה."*

### Credential-Broker (Phase-1)
- **OS-keychain כברירת-מחדל** — crate `keyring` (macOS Keychain / Windows Cred-Manager-DPAPI / Linux Secret-Service). הסוד **לא** בדיסק/`.env`, לא ב-DB (רק `keyring_ref`).
- **אימות-VCS מוגבל:** **GitHub-App + installation-token** (שעה, per-repo, bot-identity) — **לא PAT רחב.** GitLab = project-access-token.
- **brokering ל-downstream:** `op` (1Password service-account) / Vault למפתחות-שהקוד-צריך.
- **הזרקה כ-env ב-spawn בלבד**, redaction בלוגים (כמו `sanitizeLogData` ב-yemot).

### Isolation-Ring (Phase-1→2)
- **container חיצוני** (`bollard`/Docker או devcontainer CLI) תוחם blast-radius **לפני** הריצה.
- **מנועים את ה-sandbox של הסוכן** (Codex Seatbelt/Landlock, Claude sandbox) — לא ממציאים-מחדש; **מרכיבים מעל.**
- **egress-allowlist** — רשת-יוצאת רק ל-domains-מאושרים.
- **DR:** reconciliation-on-boot (סרוק `processes`+`external_resources`, אמץ/הרוג-יתומים), watchdog (systemd/launchd/Windows-Service), **mission-lease** (שני-daemons לא-יריצו-אותה-מיסיה).
- **עדכון-daemon-בזמן-מיסיה:** graceful-drain / version-pin-per-mission (לא להחליף-binary באמצע-לילה).

<a name="i18n"></a>
## י. בין-לאומיות מלאה — 23 שפות (עדיפות-משתמש מפורשת)

### רשימת-היעד (23)
`en · zh-Hans · zh-Hant · hi · es · fr · ar · bn · pt-BR · ru · ja · de · ko · vi · tr · it · fa · id · th · pl · uk · nl · **he**`
- **RTL:** he, ar, fa (+ur עתידי) → `dir="rtl"` + logical-CSS + bidi.
- **CJK:** zh-Hans/Hant, ja, ko → line-breaking בלי-רווחים, גופנים-כבדים.
- **Thai:** אין-רווחים → ICU segmentation. **Indic** (hi,bn): shaping/conjuncts, גובה-שורה.

### מחסנית קונקרטית
- **UI (React):** `i18next` + `react-i18next` + `i18next-icu` (**ICU MessageFormat** — חובה ל-plural-forms של ru/pl/ar, לא interpolation-פשוט) + `i18next-browser-languagedetector`. locale מ-OS דרך `tauri-plugin-os` (ב-Tauri אין navigator-אמין). RTL: `document.documentElement.dir=i18n.dir(lng)`. **logical-properties בלבד** (`margin-inline-start`), אף `left/right`. תאריך/מספר: `Intl.*`.
- **Rust/daemon — הנקודה שהטיוטה פספסה:** ה-daemon **לא מתרגם** — פולט **error-codes + אירועים-מובְנים** (יש כבר taxonomy), וה-UI ממפה code→string. לוגים תמיד **en+structured**. היכן שה-daemon כן צריך טקסט-משתמש (push/TTS) → crate **`fluent-templates`** (Project Fluent, bidi/plural/gender-aware), עדיף על `rust-i18n`.
- **גופנים (קריטי, לא-היה):** ארוז **Noto Sans** subsets: Latin/Cyrillic, Hebrew, Arabic, CJK-SC/TC/JP/KR, Devanagari, Bengali, Thai — variable+subsetting לא-לנפח-binary.

### תחזוקה
מקור-אמת `en`; **no-hardcoded-strings** (lint `i18next-parser` נכשל על literal ב-JSX); fallback-chain (`zh-Hant→zh-Hans→en`, `pt-BR→pt→en`); **pseudo-loc ב-CI** (`en-XA` מאריך ~40%+brackets → תופס truncation/hardcoded בלי-מתרגם, + `en-RTL`); MT-first→native-review ל-top-tier (es,fr,de,ja,zh,ar,he); Glossary (`mission`,`checkpoint`,`worktree`,`token` לא-מתורגמים); Weblate/Crowdin.

### 3 צירי-שפה (לא בינארי — היריב חידד)
`ui_lang` (עברית) · `agent_lang` (בד"כ en — מודלים-חזקים-יותר) · `output_lang` (דוח/commit/PR/הערות — אולי עברית). **שדות-נפרדים ב-Mission-Contract.** ברירת-מחדל: UI=locale, agent=en, output=locale. **מלכודת:** לתרגם בשכבת-תצוגה, לא לבקש-מהסוכן-לעבוד-בעברית.

### מלכודות RTL עברית + LTR
paths/code/terminal/diff/URL/token = **תמיד LTR** גם ב-UI-RTL → `<bdi>`/`unicode-bidi:isolate` (אחרת `src/auth/x.ts` נשבר). מספרים-מעורבים = isolation. **Timeline מעורב** (עברית-RTL ליד stack-trace-LTR) = `dir="auto"`+isolation per-segment. Terminal פנימי = `dir="ltr"` מוחלט. `overflow-x:auto` per-block ל-CJK+RTL+code.

## יא. Dual-provider — הגרסה הריאלית (תיקון היריב-2 #5)

**מה שהיה over-claimed:** "שני-סוכנים-לעולם-לא-עורכים-אותו-קובץ" + 4-workers-מקבילים + merge-queue-אוטומטי. **הבעיה:** קבצים-משותפים אמיתיים (`types.ts`, router, `package.json`/lock, migrations) שוברים בעלות-סטטית-שנקבעת-מראש; קונפליקט → סוכן-פותר (לא-דטרמיניסטי, עלול-מיזוג-נקי-אבל-שבור-סמנטית); ו-4-worktrees × node_modules = עומס-שיתקע-לפטופ.

**הגרסה הסופית ל-Phase-3:** **worker-Codex יחיד, unit-אחד-בכל-פעם, מיזוג-עם-אדם-בלולאה, ללא-פתרון-קונפליקט-אוטומטי.** תקצוב-משאבי-מכונה מפורש (CPU/RAM/דיסק/מקביליות). **מקביליות + merge-queue + cross-review-אוטומטי = מסלול-מחקר נפרד (Phase-4+), לא צ'קבוקס.** ה-Result-Packet וה-worktree-per-worker נשארים — רק המקביליות-האוטומטית יורדת מ-Phase-3.
